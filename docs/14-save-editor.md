# 14. 세이브(.FOS) 구조 분석 + 자체 세이브 에디터

원작 동봉 DOS 에디터(`EDITER.EXE` / `ITEMEDIT.EXE` / `STATEDIT.EXE`) 대신
**직접 만든 Windows용 세이브 에디터**를 쓰기 위한 리버싱 기록입니다.

- 에디터: **`editor/fos-editor.html`** (파일 하나, 더블클릭 실행 — 설치/런타임 불필요, 안드로이드 브라우저에서도 동작)
- 게임 폴더에도 복사해 둠: `F:\DGGL\Games\FT3_Win\세이브에디터.html`, `FT4_Win\세이브에디터.html`

---

## 1. 원작 동봉 에디터는 DOS 프로그램 (참고)

| 파일 | 실체 |
|---|---|
| FT3 `EDITER.EXE`, FT4 `ITEMEDIT.EXE`, `STATEDIT.EXE` | **PKLITE 압축 DOS 실행파일** (각 66,711 bytes, 내용은 서로 다름) |
| 실행 화면 | `슈퍼 그랜드 조왕 조왕 대전 파랜드 택틱스 3 에디터!!!!!` / `Game Edit Version 3.3` |
| 요구 환경 | DOSBox + 한글 폰트 (DOSBox SVN-Daum 빌드에서 정상 표시 확인) |

→ 안드로이드/Winlator 에서 쓰려면 "wine 속 DOSBox"가 필요해 번거로움 → **자체 에디터 제작으로 대체**.

---

## 2. 세이브 파일 사실

| 항목 | 값 |
|---|---|
| FT3 세이브 | `ODDATA00.FOS` … `ODDATA08.FOS` (EXE 문자열: `oddata%02d.fos`) |
| FT4 세이브 | `FO2SV_00.fos` … (EXE 문자열: `fo2sv_%02d.fos`) |
| **빈 슬롯 템플릿** | FT3 **21,304 bytes** (전부 0) — 미사용 슬롯 |
| **실제 저장된 세이브** | FT3 **21,704 bytes** (400 bytes 추가됨) |
| FT4 빈 슬롯 | 704,396 bytes (전부 0) |

> 저장하면 파일이 커집니다(템플릿 21,304 → 실제 21,704). 에디터는 두 크기를 구분합니다.

---

## 3. 확정한 필드 — **소지금**

두 세이브를 비교해 확정 (A: 소지금 200, B: 소지금 100, 다른 변경 없음):

```
오프셋 0x5480 (21,632) — 리틀엔디언 4바이트
  ODDATA00.FOS = 200  (C8 00 00 00)
  ODDATA01.FOS = 100  (64 00 00 00)
  차이 나는 다른 후보 없음(200/100 값이 각 파일에 각 1회만 존재) → 확정
```

주변 구조 (실측, 아직 미확정):

```
0x5480  200        ← 소지금
0x5484  0
0x5488  0
0x548c  199        (두 세이브 동일)
0x5490  239  279  319  359  399    ← 40씩 증가하는 표
0x54a4  427  428  429
0x54b0  449
```

그 외 세이브 특징:
- 파일 앞부분은 대부분 0 (사용량 약 6%)
- 0x26xx ~ 0x37xx 구간에 `01 XX YY` 패턴이 반복 (아이템/이벤트 플래그 목록으로 추정)
- 한글 문자열은 0x0554 의 `스크` 1곳뿐 → 파티원 이름은 세이브에 없고 **ID 참조**로 보임
  (마스터 데이터는 `DAT\Char.dat`, `ITEM.CFG`, `STAT.CFG`)

## 4. 만든 에디터 (`editor/fos-editor.html`)

| 기능 | 설명 |
|---|---|
| 파일 열기 | 클릭 선택 또는 **드래그&드롭** |
| 자동 인식 | 크기로 FT3/FT4·빈 슬롯/실제 세이브 구분, 슬롯 번호 표시 |
| **소지금** | FT3 실제 세이브에서 `0x5480` 자동 로드/적용, +1000 / 최대 / 0 버튼 |
| **값 찾아서 바꾸기** | 1/2/4바이트 검색 → 목록에서 위치 선택 → 새 값 적용 (전체 적용도 가능) |
| 저장 | 수정본을 같은 파일명으로 다운로드 → 원본에 덮어쓰기 |
| 되돌리기 | 수정 취소 |

> 소지금 위치가 확인되지 않은 게임/크기에서는 소지금 입력이 비활성화되고 "값 찾아서 바꾸기"만 동작합니다.
> 세이브 크기가 달라지는 후반 세이브에서는 소지금 오프셋도 달라질 수 있으므로 **검색 기능을 쓰는 것이 안전**합니다.

---

## 5. 검증 상태

| 항목 | 상태 |
|---|---|
| 소지금 필드 위치 | ✅ A/B 세이브 비교로 확정 |
| 게임에서 수정 세이브 로드 | ⏳ 검증 중 — 슬롯2(`ODDATA01.FOS`) 소지금을 999999로 바꿔 배치 (원본 `ODDATA01.FOS.orig`) |
| 파티 스탯/아이템 필드 | ⏳ 추가 세이브(레벨업·아이템 획득 등) 필요 |

### 추가로 필요한 세이브 (정확도 향상)
1. 레벨업(경험치 획득) 후 저장 — 전/후 값(레벨·HP·MP) 알려주기
2. 아이템 획득 후 저장 — 아이템 이름/개수
3. (FT4) 같은 방식으로 2개

→ 각 쌍을 diff 하면 해당 필드 위치가 바로 확정됩니다.
