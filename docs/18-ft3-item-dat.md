# 18. FT3 아이템 마스터(DAT\ITEM.DAT) 구조 + 아이템 에디터

FT3 는 원작이 세이브 에디터(`EDITER.EXE`)만 동봉했지만, **아이템 정의 파일**(`DAT\ITEM.DAT`)은
게임이 직접 읽는 마스터 데이터입니다 (FT3K.EXE 가 `DAT\Char.dat` 를 참조하는 것을 확인).

## 1. 레코드 구조 (260바이트 = 0x104, 총 467개)

| 오프셋 | 필드 | 비고 |
|---|---|---|
| `+0x00` | 아이템 ID (u32) | |
| `+0x04` | 이름 (CP949, 널 종료) | 예: 약초, 회복약, 요정의 눈물 |
| `+0x1C` | **사용 대상** (u16) | 1=자신, 2=?, 4=아군 전원(요정의 눈물) |
| `+0x20` | **가격** (u16) | 약초 8, 회복약 200, 요정의 눈물 500, 소머의 꽃 1500 |
| `+0x38` | **HP 회복량** (u16) | 약초 30, 호박씨 80, 회복약 150 |
| `+0x3A` | **SP 회복량** (u16) | 감자 50, 소머의 꽃 100 |
| `+0x4C` | 256(0x100) 등 플래그 | 사용 가능 여부 추정 |
| `+0x58`,`+0x5A` | 1, 255(0xFF) | 플래그 |
| `+0x60` | 소량 정수 | 2~4 |
| `+0x64~` | 설명/분류 문자열 | 예: "어디서나 볼 수 있는 일반적인 약초．ＨＰ가 ３０회복된다．" |

### 검증 방법 (설명문 자동 대조)
아이템 설명문에 들어 있는 숫자와 레코드 내 실제 수치가 일치하는지 자동 매칭:
```
약초      "ＨＰ가 ３０회복된다"   → +0x38 = 30  ✓
감자      "ＳＰ가 ５０회복된다"   → +0x3A = 50  ✓
요정의 눈물 "아군 전원의 ＨＰ가 １００회복" → +0x1C = 4(전원) +0x38 = 100 ✓
```

## 2. 에디터 지원 (editor/fos-editor.html)

| 파일 | 인식 | 표시 |
|---|---|---|
| `ODDATA*.FOS` (21,704B) | FT3 세이브 | 돈·코인 / HP·HP-MAX·SP·SP-MAX·경험치 / 직업 6슬롯×8명 |
| `fo2sv_*.fos` (704,396B) | FT4 세이브 | 돈 / 아이템 99 / 스탯 99 (CFG 정의) |
| `ITEM.DAT` (121,424B) | **FT3 아이템 마스터** | 아이템 467개 — 가격·사용대상·HP회복·SP회복 (이름 검색 지원) |

## 3. 남은 후보 (같은 방식으로 추가 가능)
- `DAT\TECH.DAT` (23,032B) — 기술/마법 정의
- `DAT\MAGIC.DAT` (6,388B) — 마법 정의
- `DAT\CLASS.DAT` (954B) — 직업 정의 (24직업)
- `DAT\CHAR.DAT` (1,316B) — 캐릭터 정의 (8명)
- `DAT\MNSTR.DAT`, `MNSTR2.DAT`, `MNSTRACT.DAT`, `MNSTTECH.DAT` — 적 정의
- `ITEM.CFG`(FT4), `STAT.CFG`(FT4) — FT4 마스터 (필드 표 자체를 담고 있음)
